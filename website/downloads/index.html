Keystore Studio for macOS

macOS 11 Big Sur or later · Apple silicon or Intel · .dmg

A signed and notarized .dmg isn't published yet. You can build one on your Mac; it runs on the Mac that built it.

  1. 1
    Install the Xcode Command Line Tools. 
    xcode-select --install
  2. 2
    Install Node 22, pnpm 10 and Rust (stable, via rustup).
  3. 3
    Clone and build the .dmg. 
    git clone https://github.com/framedparadox/keystore-studio.git
cd keystore-studio
pnpm install --frozen-lockfile
pnpm tauri build --bundles dmg
  4. 4
    Open the .dmg from src-tauri/target/release/bundle/dmg/ and drag the app to Applications. It is named Keystore Studio_1.0.0_aarch64.dmg on Apple silicon and _x64.dmg on Intel.

Moving the app to another Mac? Gatekeeper blocks unsigned apps there. See notes on unsigned builds.

Build from source

Four prerequisites. One build.

Tauri builds each installer on its own operating system, so build on the platform you want to run. A plain pnpm tauri build produces every format that system supports.

  • Node22JavaScript runtime for the UI build
  • pnpm10Package manager
  • RuststableEdition 2024, via rustup
  • Tauriv2System dependencies ›
1

Install the system dependencies

Install Visual Studio Build Tools with the Desktop development with C++ workload, then use the MSVC Rust toolchain: 

rustup default stable-msvc

WebView2 is already on current Windows 10 and 11. MSI builds use WiX v3, which needs the VBSCRIPT optional feature on Windows 11 24H2 and later (Settings → System → Optional features). 

xcode-select --install   # Xcode Command Line Tools
sudo apt-get update
sudo apt-get install -y \
  build-essential curl wget file \
  libwebkit2gtk-4.1-dev libgtk-3-dev libsoup-3.0-dev libjavascriptcoregtk-4.1-dev \
  librsvg2-dev libayatana-appindicator3-dev libssl-dev libxdo-dev
sudo dnf install -y \
  gcc gcc-c++ make curl wget file \
  webkit2gtk4.1-devel gtk3-devel libsoup3-devel javascriptcoregtk4.1-devel \
  librsvg2-devel libappindicator-gtk3-devel openssl-devel libxdo-devel
2

Clone and build

Terminal
git clone https://github.com/framedparadox/keystore-studio.git
cd keystore-studio
pnpm install --frozen-lockfile
pnpm tauri build        # writes installers to src-tauri/target/release/bundle/

pnpm tauri build runs the TypeScript check and the Vite bundle first, then compiles the Rust app in release mode.

Universal Mac build

One .dmg for Apple silicon and Intel.

rustup target add aarch64-apple-darwin x86_64-apple-darwin
pnpm tauri build --target universal-apple-darwin --bundles dmg

Unsigned on another Mac

An unsigned app opens on the Mac that built it. Elsewhere Gatekeeper reports it as damaged. To test it, right-click the app and choose Open, or clear the quarantine flag:

xattr -dr com.apple.quarantine "/Applications/Keystore Studio.app"

Windows on ARM64

WiX can't build ARM64 MSIs, so use NSIS. You also need the MSVC ARM64 build tools.

rustup target add aarch64-pc-windows-msvc
pnpm tauri build --target aarch64-pc-windows-msvc --bundles nsis

Signing, notarization, CI builds and troubleshooting are in docs/INSTALLERS.md ›

Verify

Check it before you run it.

The Windows installer isn't code-signed yet, so its checksum is how you know the file is the one we published. It takes one command.

SHA-256 Keystore Studio_1.0.0_x64-setup.exe

0e5715def11e0b6fceefe942080ea18e367698a2cb0d9c0117d8c7f92e730e1f

301,845,656 bytes

Windows PowerShell

Run it in the folder you downloaded to. PowerShell prints the hash in capitals; case doesn't matter.

Get-FileHash ".\Keystore Studio_1.0.0_x64-setup.exe" -Algorithm SHA256

Or let PowerShell compare it for you. It prints True when they match.

(Get-FileHash ".\Keystore Studio_1.0.0_x64-setup.exe" -Algorithm SHA256).Hash -eq "0e5715def11e0b6fceefe942080ea18e367698a2cb0d9c0117d8c7f92e730e1f"

macOS

Checking a copy on a Mac before moving it to a PC.

shasum -a 256 "Keystore Studio_1.0.0_x64-setup.exe"

Linux

The same check with coreutils.

sha256sum "Keystore Studio_1.0.0_x64-setup.exe"

Windows SmartScreen

“Windows protected your PC.”

SmartScreen shows this for any installer that isn't signed with a code-signing certificate yet. Signing is on the way. Until then, once the checksum matches:

  1. 1
    Open the setup file. SmartScreen stops it and offers only “Don't run”.
  2. 2
    Click More info. Check the app name reads Keystore Studio_1.0.0_x64-setup.exe. The publisher shows as “Unknown publisher” because the file is unsigned.
  3. 3

Your data

What gets installed.
Where your data lives.

Keystore contents and passwords stay in memory. They reach disk only in the keystore files you save.

Installed

  • The Keystore Studio app, with its Rust engine built in.
  • On Windows, Microsoft WebView2, only if your PC doesn't have it. Setup downloads it from Microsoft.
  • Nothing else: no services, no background updaters, no accounts.

App data folder

Session state: open keystore paths, workspaces, labels, recent files and settings, plus the vault if you set one up. No key material is stored there.

  • Windows%APPDATA%\keystore-studio
  • macOS~/Library/Application Support/keystore-studio
  • Linux~/.local/share/keystore-studio

Set KEYSTORE_STUDIO_DATA_DIR to use another folder. A folder left under the app's former name, xkeystore, moves to the new location on first start.

Uninstalling

  • Windows: Settings → Apps, find Keystore Studio, choose Uninstall.
  • The data folder is left in place, so a reinstall picks up where you left off. Delete it to remove everything.
  • In the app, Settings → Data → Reset app data clears settings, workspaces, labels, recent files and the Certificates list.

Network requests, the vault's cryptography and hardening are covered in Privacy ›

Release notes

What's in 1.0.0.

The first release. Everything below ships in the installer and in a source build.

  1. Keystores

    Open, create, edit and save PKCS#12, JKS, JCEKS, BKS, UBER and BCFKS, side by side. Convert between all six, change passwords with Save as, undo and redo, cut, copy and paste between keystores.

  2. Certificates

    PEM, DER, chains and PKCS#7 bundles on their own page. Inspect, export in any format, add to a keystore or a workspace.

  3. Convert

    Every format conversion in one place, each showing the equivalent openssl, keytool or ssh-keygen command.

  4. CA & Signing

    Sign CSRs, issue CRLs, CMS/PKCS#7 and JWT sign and verify, JAR signing that jarsigner accepts, RFC 3161 timestamps, DH parameters.

  5. Examine

    Live TLS inspection with a trust and hostname verdict against your OS trust store, a connection test, decode anything you paste, compare two certificates.

  6. Security audit

    A health score with findings for expired, expiring and weak entries, one-click key rotation and renewal, CSV report.

  7. Vault

    Remember keystore passwords under one master key (Argon2id → AES-256-GCM). Auto-locks after inactivity; your last session reopens when you unlock it.

  8. Productivity

    Command palette (Ctrl K), built-in terminal (Ctrl `), drag and drop, session restore, light, dark and system themes.

Known limitations

PKCS#11 hardware tokens and PuTTY .ppk keys aren't supported. Some Bouncy Castle edge cases are refused. Post-quantum, DSA, Ed448 and RSA-PSS keys load and save losslessly but can't sign. The timestamp authority's own chain isn't validated in the app. Details ›
